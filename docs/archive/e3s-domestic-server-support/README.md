**一句话结论**：国内一线服务器厂商的新一代机型已经提供 E3.S 配置（单机 16–48 盘），但 E3.S 目前仍主要面向全闪、AI 和 CXL 场景，U.2 仍是通用默认；信创 CPU 平台的 E3.S 选择明显更少。

## 一、结论摘要

1. **一线厂商已完成产品化。** 浪潮信息 NF5280G7（24×E3.S）、超聚变 2288H V7（48×E3.S）、新华三 R4900 G7（40×E3.S/E1.S）、联想 SR630 V3（最高 16×E3.S 1T）均可在公开规格中查到 E3.S 配置，单机 16–48 盘。
2. **二线厂商跟进。** 宁畅 R620 G50 明确给出 36×E1.S 或 36×E3.S；曙光、中兴、宝德、长城等公开披露较少，多以项目定制方式提供，建议逐项目确认。
3. **E3.S 仍是"可选项"而非默认项。** 通用机型默认仍是 U.2 2.5 英寸；E3.S 集中在全闪 SDS、AI 推理、CXL 内存扩展等高价值场景，常见 CTO/项目定制。
4. **形态分工清晰。** 2U 高密全闪走 E3.S，1U/2U 计算节点走 E1.S，通用与存量走 U.2；上一代机型（如新华三 R4900 G6）高密前置为 32×E1.S，公开用户指南未见 E3.S。
5. **国产 SSD 已能配套。** 忆恒创源 PBlaze7 7940 覆盖 U.2/HHHL AIC/E1.S/E3.S，大普微已展示 Gen5 E3.S 方案；瓶颈更多在背板、PCIe 交换、RAID/HBA、整机验证和运维体系，而不是"没有盘"。
6. **信创 CPU 平台明显滞后。** 鲲鹏、海光、飞腾平台的公开 E3.S 高密配置较少。信创全闪项目应提前锁定 BOM 并做兼容性验证，必要时回退 U.2。

| 华为 | TaiShan（鲲鹏）系列 | 公开资料未突出 E3.S 高密配置；原 x86 服务器业务由超聚变承接 | 公开资料 |
| 曙光/中兴/宝德/长城等 | 新一代 2U | 公开资料披露有限，多以项目定制/CTO 方式提供，需逐项目确认 | — |

补充说明：

- 表中"支持"指公开资料可查到 E3.S 背板或整机配置。实际可订购性、盘位数、盘型与固件版本强相关，应以厂商配置器和报价为准。
- 48 盘、40 盘、36 盘这类高密配置通常需要 PCIe Switch 扩展上游通道，成本和功耗明显高于 24 盘方案；24 盘及以下更容易直连 CPU。
- 联想 SR630 V3 是 1U 机型，16×E3.S 属于高密全闪配置；2U 机型是否提供 E3.S，需按具体型号和 CTO 配置确认。
- 华为原 x86 服务器业务已由超聚变承接；华为品牌 TaiShan（鲲鹏）服务器在公开资料中未把 E3.S 作为标准高密选项。

## 三、E3.S、E1.S 与 U.2 的定位差异

| 形态 | 尺寸/高度 | 2U 典型盘位 | 优势 | 局限 | 适用场景 |
|---|---|---|---|---|---|
| U.2 | 2.5 英寸，7/15mm | 24–25 | 生态成熟、盘源多、成本低 | 密度和散热一般，线缆多 | 通用虚拟化、存量业务 |
| E1.S | 1U 高，9.5/15mm | 32–40 | 1U/2U 高密、成本较低、风道好 | 单盘容量和功耗受限 | 计算节点、边缘、高密 |
| E3.S | 2U 高，7.5/16.8mm | 24–48 | 高密、大容量、热插拔、cable-less | 背板/交换成本高，盘价高 | 全闪 SDS、AI、CXL |

E3.S 1T（7.5mm）偏重密度，E3.S 2T（16.8mm）偏重大容量；E1.S 是 1U 高形态，两者不能混为一谈。国内厂商在 2U 全闪机型上更倾向 E3.S，在 1U 和计算型 2U 上更倾向 E1.S。

以 30.72TB 盘估算，24×E3.S 裸容量约 737TB，48×E3.S 约 1.47PB。48 盘方案适合 AI 推理、向量库、全闪 SDS 等容量密集型场景，但要评估 PCIe Switch 带来的成本、功耗和故障域。

## 四、国产 SSD 配套进展

- **忆恒创源 PBlaze7 7940**：PCIe 5.0，支持 2.5 英寸 U.2、HHHL AIC、E1.S、E3.S 多种形态，可作为国产 E3.S 盘源。
- **大普微**：已展示 Gen5 E3.S SSD 方案，并与 SupremeRAID 等 RAID 加速方案联测。
- **紫光闪存、长江存储等**：已推出 PCIe 5.0 企业级盘，E3.S 形态与容量点需按具体型号确认。
- 选型时重点核对：容量点（7.68/15.36/30.72TB）、DWPD、功耗、掉电保护、固件兼容性和整机 AVL。

## 五、选型与采购建议

1. **先定场景，再定形态。** 全闪 SDS、AI 推理、CXL 缓存优先 E3.S；通用虚拟化和存量业务继续 U.2；1U 计算和边缘优先 E1.S。
2. **把"支持 E3.S"拆成可验收的 BOM。** 至少确认：背板料号、最大盘数、上游 PCIe lane/Switch、RAID/HBA 型号、电源与风扇配置、盘 AVL。
3. **高密不等于划算。** 36–48 盘机型要核算 PCIe Switch、功耗、散热和故障域；24 盘直连方案在很多业务里性价比更高。
4. **信创项目先验证。** 确认 CPU 平台、OS、RAID 卡、国产盘固件与 E3.S 背板的兼容性；公开资料少时，要求厂商提供同配置实测报告。
5. **合同与验收。** 写明 E3.S 盘位数、支持盘型、热插拔、功耗、质保和备件；PoC 验证带宽、IOPS、掉电保护和故障恢复。

## 六、风险与信息边界

- 本文基于公开产品页、用户指南和产品白皮书，资料截止 2026-11-04；CTO 配置和区域报价可能不同。
- "未见公开支持"不等于"不支持"，部分厂商仅在项目投标或行业客户中提供 E3.S。
- E3.S 盘源、价格和交期仍在变化，U.2 的存量生态和成本优势依然很强。
- 本文未做整机实测，建议在 PoC 中补充性能、功耗、散热和可靠性验证。
